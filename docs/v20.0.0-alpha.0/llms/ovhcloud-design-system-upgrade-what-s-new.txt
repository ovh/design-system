# What's new

*Release notes of the current major version, v20. Earlier versions are listed under [What's new in previous versions](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/whats-new-v19); the [Changelog](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/changelog) lists every change.*

## v20.0.0-alpha.0

First prerelease of v20. It is published under the `alpha` tag: install it with `npm install @ovhcloud/ods-react@alpha @ovhcloud/ods-themes@alpha`, the `latest` tag stays on v19. Its API may still change before v20.0.0.

v20 has breaking changes in the component API and in the theme. Follow the [Migration 19.x to 20.x](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/migration-19-to-20) guide before you upgrade.

### Project changes

- **React 19** is supported, and React 18 still is: the peer dependency range is unchanged.
- **Themes** are rebuilt on a semantic layer of tokens, and the default theme gets a new, neutral look. Four themes are shipped, each as one complete stylesheet: the default theme (Aluminium), its dark mode, Blue Jeans (the OVHcloud look) and its dark mode. See [Themes](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/themes).
- **Documentation** moves from Storybook to a new documentation website, published as `@ovhcloud/ods-docs` in place of `@ovhcloud/ods-storybook`.
- **APIs deprecated in v19 are removed**, the Switch component among them. The `color` prop is removed too, in favor of `status` where the component has one.

### New packages

**@ovhcloud/ods-mcp**

An MCP server that gives AI assistants access to the ODS documentation. [See Documentation](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/mcp-server).

**@ovhcloud/ods-tailwind**

Tailwind CSS v4 utilities mapped to the ODS tokens. [See Documentation](https://ovh.github.io/design-system/v20.0.0-alpha.0/guides/tailwind).

### New components

**Command**

[See Documentation](https://ovh.github.io/design-system/v20.0.0-alpha.0/components/command).

### Feature updates

**Accordion**
- New attribute `emphasis` has been added.

**Badge**
- New attributes `status` and `emphasis` have been added.

**Button**
- New attributes `status` and `emphasis` have been added, `emphasis` replaces `variant`.

**Card**
- New attribute `status` has been added.

**Drawer**
- New attribute `backdrop` has been added. With it, the page no longer scrolls and a click on the backdrop closes the drawer.

**Input**
- New attributes `startContent` and `endContent` have been added.

**Message**
- New attributes `status` and `emphasis` have been added, `emphasis` replaces `variant`.

**Pagination**
- New attributes `getPageUrl` and `linkAs` have been added, to render the pages as links.

**Spinner**
- New CSS custom property `--ods-spinner-color` has been added.

**Table**
- New attribute `striped` has been added, it replaces `variant`.

**Tabs**
- New attribute `mountStrategy` has been added, to choose when the content of the inactive panels is rendered.

**Tag**
- New attribute `status` has been added.

**Toaster**
- New method `toast.accent()` has been added, it replaces `toast.primary()`.
