# Form Field

## Default

```tsx
<FormField>
  <Textarea name="textarea" />
</FormField>
```

## Label

```tsx
<FormField>
  <FormFieldLabel>
    Description:
  </FormFieldLabel>

  <Textarea name="textarea" />
</FormField>
```

## Label Sub Label

```tsx
<FormField>
  <FormFieldLabel>
    Description
    <FormFieldLabelSubLabel>- mandatory</FormFieldLabelSubLabel>
  </FormFieldLabel>

  <Textarea name="textarea" />
</FormField>
```

## Helper

```tsx
<FormField>
  <Textarea name="textarea" />

  <FormFieldHelper>
    <Text preset={ TEXT_PRESET.caption }>
      Helper text
    </Text>
  </FormFieldHelper>
</FormField>
```

## Error

```tsx
<FormField invalid>
  <Textarea name="textarea" />

  <FormFieldError>
    Error message
  </FormFieldError>
</FormField>
```

## Accessibility Label

```tsx
<FormField>
  <FormFieldLabel>
    Login:
  </FormFieldLabel>

  <Input name="input" />

  <FormFieldHelper>
    Username or email address
  </FormFieldHelper>
</FormField>
```
