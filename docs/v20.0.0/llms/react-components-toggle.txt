# Toggle

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `checked` | `boolean` | No | undefined | The controlled checked state of the toggle. |
| `children` | `ReactNode` | Yes | undefined | The parts of the toggle to render: a ToggleControl, and a ToggleLabel if needed. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `invalid` | `boolean` | No | undefined | Whether the component is in error state. |
| `name` | `string` | No | undefined | The name of the form element. Useful for form submission. |
| `onCheckedChange` | `(detail: ToggleCheckedChangeDetail) => void` | No | undefined | Callback fired when the checked state changes. |
| `required` | `boolean` | No | undefined | Whether the component is required. |
| `value` | `string` | No | undefined | The value of form element. Useful for form submission. |
| `withLabels` | `boolean` | No | undefined | Whether the component displays "ON/OFF" labels. |
