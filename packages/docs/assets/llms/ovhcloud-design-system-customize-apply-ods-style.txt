# Apply ODS Style

After installing ODS (following the [Get Started](https://ovh.github.io/design-system/v19.7.3/guides/get-started) documentation),
you'll be able to use every component with the correct style.

For the non-component related style, you need to update your app accordingly.

## Use the ODS font

ODS components do not enforce any font by default (except for a few, like `Code`).

To use one of the ODS fonts in your app, add the expected variables to the top of your app:

```css
html {
  font-family: var(--ods-semantic-font-family-body);
}
```

## Use the ODS design tokens

All ODS components are using common design tokens, that are accessible through [CSS variables](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties).

If you want to use any of those on your own components, you can refer to the exhaustive list on the [Design Tokens](https://ovh.github.io/design-system/v19.7.3/guides/design-tokens) page.

```css
.my-custom-title {
  color: var(--ods-semantic-color-content-text);
  ...
}
```

## Use ODS CSS reset

We recommend you to import the ODS CSS reset subset of rules to normalize the rendering of some elements, but it's not mandatory.

```typescript
import '@ovhcloud/ods-react/normalize-css';
```
