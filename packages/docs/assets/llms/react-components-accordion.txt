# Accordion

_An **Accordion** is a vertical header that reveals or hides an associated section of content._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultValue` | `string[]` | No | undefined | The initial value of the expanded accordion items. Use when you don't need to control the value of the accordion. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `emphasis` | `ACCORDION_EMPHASIS` | No | undefined | The emphasis preset to use, setting the visual weight of all the accordion items. |
| `multiple` | `boolean` | No | undefined | Whether multiple accordion items can be expanded at the same time. |
| `onChange` | `(detail: AccordionChangeDetail) => void` | No | undefined | Callback fired when the state of expanded/collapsed accordion items changes. |
| `value` | `string[]` | No | undefined | The controlled value of the expanded accordion items. |
