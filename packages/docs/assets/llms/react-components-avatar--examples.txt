# Avatar

## Default

```tsx
<Avatar />
```

## Initials

```tsx
<Avatar>
  JD
</Avatar>
```

## With Image

```tsx
<Avatar src="https://images.crunchbase.com/image/upload/c_pad,h_160,w_160,f_auto,b_white,q_auto:eco,dpr_1/fhi0pe8wd87fvujy9yk8" />
```

## With Fallback

```tsx
<Avatar
  fallback={"J"}
  src="https://invalid-url.example.com/avatar.png" />
```

## With Icon

```tsx
<Avatar>
  <Icon name={ ICON_NAME.sparkle } />
</Avatar>
```
