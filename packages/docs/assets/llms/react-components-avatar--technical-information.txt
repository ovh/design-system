# Avatar

## Avatar

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `fallback` | `ReactNode` | No | undefined | Fallback content to display when the image fails to load. Defaults to a user icon. |
| `src` | `string` | No | undefined | The image source URL. |

## CSS Variables

| Variable | Default value |
|---|---|
| `--ods-avatar-background-color` | `var( --ods-color-primary-500 )` |
| `--ods-avatar-text-color` | `var(--ods-color-neutral-000)` |
| `--ods-avatar-border-radius` | `50%` |
| `--ods-avatar-size` | `24px` |
| `--ods-avatar-object-fit` | `cover` |
