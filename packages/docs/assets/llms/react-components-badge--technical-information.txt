# Badge

## Badge

This component extends all the native `<span>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `emphasis` | `BADGE_EMPHASIS` | No | undefined | The emphasis preset to use, from the strongest (high) to the lightest (low) visual weight. |
| `size` | `'lg' | 'md' | 'sm'` | No | undefined | The size preset to use. |
| `status` | `BADGE_STATUS` | No | undefined | The status preset to use. |

## Enums

### BADGE_EMPHASIS

- `high` = `high`
- `low` = `low`
- `medium` = `medium`

### BADGE_SIZE

- `lg` = `lg`
- `md` = `md`
- `sm` = `sm`

### BADGE_STATUS

- `accent` = `accent`
- `alpha` = `alpha`
- `beta` = `beta`
- `critical` = `critical`
- `information` = `information`
- `neutral` = `neutral`
- `new` = `new`
- `promotion` = `promotion`
- `success` = `success`
- `warning` = `warning`
