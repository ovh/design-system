# Badge

_**Badge** show concise metadata or the current status for an item, in a compact format._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `'critical' | 'information' | 'neutral' | 'primary' | 'success' | 'warning' | 'alpha' | 'beta' | 'new' | 'promotion'` | No | undefined | The color preset to use. |
| `size` | `'lg' | 'md' | 'sm'` | No | undefined | The size preset to use. |
