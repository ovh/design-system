# Breadcrumb

_A list of <DocLink to="/components/link">Links</DocLink> showing the current page location in the navigational hierarchy._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `collapseThreshold` | `number` | No | undefined | The number of items when the component will collapse to an ellipsis. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `locale` | `'de' | 'en' | 'es' | 'fr' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `nbItemsAfterEllipsis` | `number` | No | undefined | The number of items to display before the ellipsis. |
| `nbItemsBeforeEllipsis` | `number` | No | undefined | The number of items to display after the ellipsis. |
| `noCollapse` | `boolean` | No | undefined | Whether the component should not collapse in an ellipsis regarding the number of items. |
| `onExpand` | `() => void` | No | undefined | Callback fired when an ellipsis is expanded. |
