# Button

## Button

This component extends all the native `<button>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `BUTTON_COLOR` | No | undefined | The color preset to use. |
| `loading` | `boolean` | No | undefined | Whether the component is in loading state, disabling it. |
| `size` | `'xs' | 'sm' | 'md'` | No | undefined | The size preset to use. |
| `variant` | `'default' | 'ghost' | 'outline'` | No | undefined | The variant preset to use. |

## Enums

### BUTTON_COLOR

- `critical` = `critical`
- `information` = `information`
- `neutral` = `neutral`
- `primary` = `primary`
- `success` = `success`
- `warning` = `warning`

### BUTTON_SIZE

- `md` = `md`
- `sm` = `sm`
- `xs` = `xs`

### BUTTON_VARIANT

- `default` = `default`
- `ghost` = `ghost`
- `outline` = `outline`
