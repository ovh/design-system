# Button

## Button

This component extends all the native `<button>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `emphasis` | `BUTTON_EMPHASIS` | No | undefined | The emphasis preset to use, setting the visual weight of the button. |
| `loading` | `boolean` | No | undefined | Whether the component is in loading state, disabling it. |
| `size` | `'xs' | 'sm' | 'md'` | No | undefined | The size preset to use. |
| `status` | `BUTTON_STATUS` | No | undefined | The status preset to use. |

## Enums

### BUTTON_EMPHASIS

- `high` = `high`
- `low` = `low`
- `medium` = `medium`

### BUTTON_SIZE

- `md` = `md`
- `sm` = `sm`
- `xs` = `xs`

### BUTTON_STATUS

- `brand` = `brand`
- `critical` = `critical`
- `neutral` = `neutral`
