# Button Group

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultValue` | `(string | number | readonly string[]) & string[]` | No | undefined | The initial value of the selected items. Use when you don't need to control the value of the component. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `multiple` | `boolean` | No | undefined | Whether multiple items can be selected at the same time. |
| `onValueChange` | `(detail: ButtonGroupValueChangeDetail) => void` | No | undefined | Callback fired when the selection changes. |
| `size` | `'xs' | 'sm' | 'md'` | No | undefined | The size preset to use. |
| `value` | `string[]` | No | undefined | The controlled value of the selected items. |
