# Button

_A **Button** component aims to initiate an action. Its text indicates the related intent, its aspect describes the importance and influence level._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `BUTTON_COLOR` | No | undefined | The color preset to use. DEPRECATED: Use the `status` prop instead (information, success and warning have no status equivalent), color will be removed in v21. (deprecated) |
| `loading` | `boolean` | No | undefined | Whether the component is in loading state, disabling it. |
| `size` | `'xs' | 'sm' | 'md'` | No | undefined | The size preset to use. |
| `status` | `BUTTON_STATUS` | No | undefined | The status preset to use. |
| `variant` | `'default' | 'ghost' | 'outline'` | No | undefined | The variant preset to use. |
