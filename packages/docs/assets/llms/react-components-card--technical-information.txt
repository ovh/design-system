# Card

## Card

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `CARD_COLOR` | No | undefined | The color preset to use. |

## Enums

### CARD_COLOR

- `critical` = `critical`
- `information` = `information`
- `neutral` = `neutral`
- `primary` = `primary`
- `success` = `success`
- `warning` = `warning`
