# Clipboard

## Clipboard

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override (see Input i18n keys). |
| `locale` | `'fr' | 'de' | 'en' | 'es' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `onCopy` | `() => void` | No | undefined | Callback fired when the input value is copied. |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
| `value` | `string` | No | undefined | The input value. |

## ClipboardControl

This component extends all the native `<input>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `loading` | `boolean` | No | undefined | Whether the component is in loading state. |
| `maskOption` | `object` | No | undefined | Whether the masked display is active and its initial state. |

## ClipboardTrigger

This component extends all the native `<button>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `labelCopy` | `string` | No | undefined | The initial tooltip label on copy button. |
| `labelCopySuccess` | `string` | No | undefined | The tooltip label on copy button after a successful copy. |
