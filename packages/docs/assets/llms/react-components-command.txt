# Command

_The **Command** component provides a fast and efficient way to search, filter, and trigger actions from anywhere in an application._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `backdropStyle` | `CSSProperties` | No | undefined | Custom style applied to the modal backdrop. Useful if you want to override the backdrop z-index. |
| `closeOnEscape` | `boolean` | No | undefined | Whether to close the modal when the escape key is pressed. |
| `closeOnInteractOutside` | `boolean` | No | undefined | Whether to close the modal when the outside is clicked. |
| `defaultOpen` | `boolean` | No | undefined | The initial open state of the modal. Use when you don't need to control the open state of the modal. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `initialFocusedElement` | `() => null | HTMLElement` | No | undefined | Element that receive the focus when the dialog is opened. |
| `locale` | `'de' | 'en' | 'es' | 'fr' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `onOpenChange` | `(detail: ModalOpenChangeDetail) => void` | No | undefined | Callback fired when the modal open state changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the modal. |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
