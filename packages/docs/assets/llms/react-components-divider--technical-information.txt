# Divider

## Divider

This component extends all the native `<hr>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `'neutral' | 'primary'` | No | undefined | - (deprecated) |
| `orientation` | `'horizontal' | 'vertical'` | No | undefined | The orientation of the divider. |
| `spacing` | `'0' | '2' | '4' | '6' | '8' | '12' | '16' | '24' | '32' | '40' | '48' | '64'` | No | undefined | The spacing preset to use. |
