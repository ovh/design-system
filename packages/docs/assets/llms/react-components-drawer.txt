# Drawer

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `backdrop` | `boolean` | No | undefined | Whether a backdrop is displayed. With a backdrop, the drawer behaves as a modal: focus is trapped, the rest of the page is inert and its scroll is locked. |
| `backdropStyle` | `CSSProperties` | No | undefined | Custom style applied to the drawer backdrop. Useful if you want to override the backdrop z-index. |
| `closeOnEscape` | `boolean` | No | undefined | Whether to close the drawer when the escape key is pressed. |
| `closeOnInteractOutside` | `boolean` | No | undefined | Whether to close the drawer when the user clicks or moves the focus outside of it. Defaults to true when a backdrop is displayed, false otherwise. |
| `defaultOpen` | `boolean` | No | undefined | The initial open state of the drawer. Use when you don't need to control the open state of the drawer. |
| `onOpenChange` | `(detail: DrawerOpenChangeDetail) => void` | No | undefined | Callback fired when the drawer open state changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the drawer. |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. |
