# Editable

## Editable

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultEditing` | `boolean` | No | undefined | The initial editing state of the editable. Use when you don't need to control the editing state of the editable. |
| `editing` | `boolean` | No | undefined | The controlled editing state of the editable. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `locale` | `'fr' | 'de' | 'en' | 'es' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `onCancel` | `() => void` | No | undefined | Callback fired when the cancel trigger is activated. |
| `onEditChange` | `(detail: EditableEditingChangeDetail) => void` | No | undefined | Callback fired when the editing state changes. |
| `onSubmit` | `() => void` | No | undefined | Callback fired when the submit trigger is activated. |

## EditableActions

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `children` | `(props: object) => ReactNode` | No | undefined | Custom actions render function, that provides Editable current state. |
