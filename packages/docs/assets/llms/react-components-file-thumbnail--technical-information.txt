# File Thumbnail

## FileThumbnail

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `dismissible` | `boolean` | No | undefined | Whether the component holds a dismiss button. |
| `error` | `string` | No | undefined | The file error message to display. |
| `file` | `File` | Yes | undefined | The current File object. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `locale` | `'de' | 'en' | 'es' | 'fr' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for size formatting and the translation of the internal elements. |
| `onFileRemove` | `(detail: FileThumbnailRemoveDetail) => void` | No | undefined | Callback fired when the file is removed. |
| `progress` | `number` | No | undefined | The file upload progress. |
