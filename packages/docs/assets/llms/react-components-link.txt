# Link

_**Link** is a component that enables redirection to a new page, section, website or other resources:_

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `as` | `T` | No | 'a' | Pass a component you may want to use as custom Link component. Useful for example when using routing library like react-router. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |

## Examples

- Default
- Disabled
- With icon
- Accessibility - File download
- Accessibility - Icon only link
- Accessibility - In a new tab
