# Logo

## Logo

This component extends all the native `<svg>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `size` | `'lg' | 'md' | 'sm'` | No | undefined | The size preset to use. |
| `variant` | `'default' | 'emblem'` | No | undefined | The variant preset to use. |

## Enums

### LOGO_SIZE

- `lg` = `lg`
- `md` = `md`
- `sm` = `sm`

### LOGO_VARIANT

- `default` = `default`
- `emblem` = `emblem`
