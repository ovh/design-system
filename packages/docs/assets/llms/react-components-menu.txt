# Menu

_A Menu component provides a list of options or actions that appear when a user interacts with its trigger element._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `onOpenChange` | `(detail: MenuOpenChangeDetail) => void` | No | undefined | Callback fired when the menu open state changes. |
| `onPositionChange` | `(detail: MenuPositionChangeDetail) => void` | No | undefined | Callback fired when the menu position changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the menu. |
| `overlayConfig` | `object` | No | undefined | The overlay configuration. |
| `position` | `'left' | 'right' | 'bottom' | 'bottom-end' | 'bottom-start' | 'left-end' | 'left-start' | 'right-end' | 'right-start' | 'top' | 'top-end' | 'top-start'` | No | undefined | - (deprecated) |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
| `triggerId` | `string` | No | undefined | ID of an external trigger element to use in place of the MenuTrigger component. |
