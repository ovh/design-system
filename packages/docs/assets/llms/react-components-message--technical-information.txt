## Message

| `dismissible` | `boolean` | No | undefined | Whether the remove button is displayed. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `locale` | `'de' | 'en' | 'es' | 'fr' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `onRemove` | `() => void` | No | undefined | Callback fired when the close button is pressed. |
| `variant` | `'default' | 'light'` | No | undefined | The variant preset to use. |
