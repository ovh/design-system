# Message Bubble

_The **Message Bubble** component is designed to display messages in a conversational interface._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `error` | `boolean` | No | undefined | Indicates an error state |
| `typing` | `boolean` | No | undefined | When typing a message |
| `variant` | `'ai' | 'human'` | No | undefined | Visual variant of the message bubble |
