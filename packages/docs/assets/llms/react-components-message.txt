# Message

_**Message** component helps to communicate with users providing feedback or information._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `dismissible` | `boolean` | No | undefined | Whether the remove button is displayed. |
| `emphasis` | `MESSAGE_EMPHASIS` | No | undefined | The emphasis preset to use, from the strongest (high) to the lightest (low) visual weight. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `locale` | `'de' | 'en' | 'es' | 'fr' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `onRemove` | `() => void` | No | undefined | Callback fired when the close button is pressed. |
| `status` | `MESSAGE_STATUS` | No | undefined | The status preset to use. |
