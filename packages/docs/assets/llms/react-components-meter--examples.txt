# Meter

## Default

```tsx
<Meter aria-label="Gauge" />
```

## Thresholds

```tsx
<>
  <p>Value under low threshold:</p>
  <Meter
    aria-label="Value under low threshold"
    low={ 40 }
    value={ 35 } />

  <p>Value between both thresholds:</p>
  <Meter
    aria-label="Value between both thresholds"
    high={ 80 }
    low={ 40 }
    value={ 60 } />

  <p>Value above high threshold:</p>
  <Meter
    aria-label="Value above high threshold"
    high={ 80 }
    value={ 90 } />
</>
```

## Optimum

```tsx
<>
  <p>Low optimum and low value:</p>
  <Meter
    aria-label="Low optimum and low value"
    high={ 80 }
    low={ 40 }
    optimum={ 30 }
    value={ 20 } />

  <p>Low optimum and high value:</p>
  <Meter
    aria-label="Low optimum and high value"
    high={ 80 }
    low={ 40 }
    optimum={ 30 }
    value={ 60 } />

  <p>Low optimum and very high value:</p>
  <Meter
    aria-label="Low optimum and very high value"
    high={ 80 }
    low={ 40 }
    optimum={ 30 }
    value={ 90 } />
</>
```

## Accessibility Aria Label

```tsx
<Meter
  aria-label="Gauge"
  low={ 40 }
  value={ 35 } />
```

## Accessibility Aria Labelledby

```tsx
<>
  <Text
    id="meter-label"
    preset={ TEXT_PRESET.label }>
    Gauge:
  </Text>

  <Meter
    aria-labelledby="meter-label"
    low={ 40 }
    value={ 35 } />
</>
```

## Accessibility Aria Valuetext

```tsx
<Meter
  aria-label="Gauge"
  aria-valuetext="35 files uploaded"
  low={ 40 }
  value={ 35 } />
```
