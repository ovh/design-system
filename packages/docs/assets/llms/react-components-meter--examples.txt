# Meter

## Accessibility Aria Label

```tsx
<Meter
  aria-label="Gauge"
  low={ 40 }
  value={ 35 } />
```

## Accessibility Aria Labelledby

```tsx
<>
  <Text
    id="meter-label"
    preset={ TEXT_PRESET.label }>
    Gauge:
  </Text>

  <Meter
    aria-labelledby="meter-label"
    low={ 40 }
    value={ 35 } />
</>
```

## Accessibility Aria Valuetext

```tsx
<Meter
  aria-label="Gauge"
  aria-valuetext="35 files uploaded"
  low={ 40 }
  value={ 35 } />
```

## Default

```tsx
<Meter />
```
