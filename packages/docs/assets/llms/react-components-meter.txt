# Meter

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `high` | `number` | No | undefined | The lower numeric bound of the high end of the measured range. |
| `low` | `number` | No | undefined | The upper numeric bound of the low end of the measured range. |
| `max` | `number` | No | undefined | The upper numeric bound of the measured range. |
| `min` | `number` | No | undefined | The lower numeric bound of the measured range. |
| `optimum` | `number` | No | undefined | The optimal numeric value. Combined with low and high, it will changes the coloring behaviour. |
| `value` | `number` | No | undefined | The current value of the meter |
