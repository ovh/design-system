# Popover

## Popover


| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `autoFocus` | `boolean` | No | undefined | Whether to automatically set focus on the first focusable content within the popover when opened. |
| `gutter` | `number` | No | undefined | - (deprecated) |
| `onOpenChange` | `(detail: PopoverOpenChangeDetail) => void` | No | undefined | Callback fired when the popover open state changes. |
| `onPositionChange` | `(detail: PopoverPositionChangeDetail) => void` | No | undefined | Callback fired when the popover position changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the popover. |
| `overlayConfig` | `object` | No | undefined | The overlay configuration. |
| `position` | `'left' | 'right' | 'bottom' | 'top' | 'bottom-end' | 'bottom-start' | 'left-end' | 'left-start' | 'right-end' | 'right-start' | 'top-end' | 'top-start'` | No | undefined | - (deprecated) |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
| `sameWidth` | `boolean` | No | undefined | - (deprecated) |
| `triggerId` | `string` | No | undefined | ID of an external trigger element to use in place of the PopoverTrigger component. |

## PopoverContent

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `createPortal` | `boolean` | No | undefined | Whether the component should be rendered in the DOM close to the body tag. |
| `withArrow` | `boolean` | No | undefined | Whether the component displays an arrow pointing to the trigger. |

## PopoverTrigger

This component extends all the native `<button>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `asChild` | `boolean` | No | undefined | Use the provided child element as the default rendered element, combining their props and behavior. Be careful to pass an actual Node, not a Fragment. |
