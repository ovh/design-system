# Popover

_**Popover** component is triggered by click and is used to provide additional information to the user in a new temporary surface that overlays the page_

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `autoFocus` | `boolean` | No | undefined | Whether to automatically set focus on the first focusable content within the popover when opened. |
| `onOpenChange` | `(detail: PopoverOpenChangeDetail) => void` | No | undefined | Callback fired when the popover open state changes. |
| `onPositionChange` | `(detail: PopoverPositionChangeDetail) => void` | No | undefined | Callback fired when the popover position changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the popover. |
| `overlayConfig` | `object` | No | undefined | The overlay configuration. |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
| `triggerId` | `string` | No | undefined | ID of an external trigger element to use in place of the PopoverTrigger component. |
