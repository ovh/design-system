# Progress Bar

## ProgressBar

This component extends all the native `<progress>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `max` | `string | number` | No | undefined | The maximum value of the progress bar. |
| `value` | `string | number` | No | undefined | The current value of the progress bar |

## CSS Variables

| Variable | Default value |
|---|---|
| `--ods-progress-bar-border-radius` | `var(--ods-theme-border-radius)` |
