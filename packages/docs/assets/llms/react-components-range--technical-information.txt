# Range

## Range

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `aria-label` | `string[]` | No | undefined | The aria-label of each slider thumb. Useful for providing an accessible name to the slider. |
| `aria-labelledby` | `string[]` | No | undefined | The id of the elements that labels each slider thumb. Useful for providing an accessible name to the slider. |
| `defaultValue` | `number[]` | No | undefined | The initial selected value(s). Use when you don't need to control the value(s) of the range. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `displayBounds` | `boolean` | No | undefined | Whether the range bounds are displayed under the track. |
| `displayTooltip` | `boolean` | No | undefined | Whether a tooltip with the current thumb value is displayed on drag. |
| `invalid` | `boolean` | No | undefined | Whether the component is in error state. |
| `max` | `number` | No | undefined | The maximum value that can be selected. |
| `min` | `number` | No | undefined | The minimum value that can be selected. |
| `name` | `string` | No | undefined | The name of the form element. Useful for form submission. |
| `onDragging` | `(detail: RangeValueChangeDetail) => void` | No | undefined | Callback fired when the thumb moves. |
| `onValueChange` | `(detail: RangeValueChangeDetail) => void` | No | undefined | Callback fired when the thumb is released. |
| `step` | `number` | No | undefined | The amount to increment or decrement the value by. |
| `ticks` | `RangeTickItem[]` | No | undefined | List of tick indicators to display alongside the range. |
| `value` | `number[]` | No | undefined | The controlled selected value(s). |

## Types

- `RangeTickItem`: `number | RangeTickCustomItem`

## CSS Variables

| Variable | Default value |
|---|---|
| `--ods-range-track-border-radius` | `calc(var(--ods-theme-border-radius) / 2)` |
| `--ods-range-thumb-background-color` | `var(--ods-color-neutral-000)` |
