# Select

_**Select** component is used to select one or more items from a list of values_

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultOpen` | `boolean` | No | undefined | The initial open state of the select. Use when you don't need to control the open state of the select. |
| `defaultValue` | `string[] | string` | No | undefined | The initial selected value(s). Use when you don't need to control the selected value(s) of the select. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `fitControlWidth` | `boolean` | No | undefined | - (deprecated) |
| `invalid` | `boolean` | No | undefined | Whether the component is in error state. |
| `items` | `SelectItem<CustomData>[]` | Yes | undefined | The list of items |
| `multiple` | `SelectMultipleMode` | No | undefined | Allows multiple selection and define how it should be rendered. |
| `name` | `string` | No | undefined | The name of the form element. Useful for form submission. |
| `onOpenChange` | `(detail: SelectOpenChangeDetail) => void` | No | undefined | Callback fired when the select open state changes. |
| `onValueChange` | `(detail: SelectValueChangeDetail) => void` | No | undefined | Callback fired when the value(s) changes. |
| `open` | `boolean` | No | undefined | The controlled open state of the select. |
| `overlayConfig` | `object` | No | undefined | The overlay configuration. |
| `positionerStyle` | `CSSProperties` | No | undefined | Custom style applied to the overlay positioner. Useful if you want to override the overlay z-index. |
| `readOnly` | `boolean` | No | undefined | Whether the component is readonly. |
| `required` | `boolean` | No | undefined | Whether the component is required. |
| `value` | `string[]` | No | undefined | The controlled selected value(s). |
