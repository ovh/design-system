# Spinner

```tsx
<>
  <Spinner color={ SPINNER_COLOR.neutral } />
  <Spinner color={ SPINNER_COLOR.primary } />
</>
```

## Default

```tsx
<Spinner />
```

## Size

```tsx
<>
  <Spinner size={ SPINNER_SIZE.xs } />
  <Spinner size={ SPINNER_SIZE.sm } />
```
