# Spinner

## Spinner

This component extends all the native `<span>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `'neutral' | 'primary'` | No | undefined | The color preset to use. |
| `size` | `'xs' | 'sm' | 'md' | 'lg'` | No | undefined | The size preset to use. |

## Enums

### SPINNER_COLOR

- `neutral` = `neutral`
- `primary` = `primary`

### SPINNER_SIZE

- `lg` = `lg`
- `md` = `md`
- `sm` = `sm`
- `xs` = `xs`
