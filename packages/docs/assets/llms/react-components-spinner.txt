# Spinner

_A visual indicator that a process is happening in the background but the interface is not yet ready for interaction._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `color` | `SPINNER_COLOR` | No | undefined | The color preset to use. DEPRECATED: Set the --ods-spinner-color CSS custom property instead, color will be removed in v21. (deprecated) |
| `size` | `'xs' | 'sm' | 'md' | 'lg'` | No | undefined | The size preset to use. |
