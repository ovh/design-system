# Switch

## Switch

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultValue` | `string` | No | undefined | The initial value of the selected item. Use when you don't need to control the value of the switch. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `onValueChange` | `(detail: SwitchValueChangeDetail) => void` | No | undefined | Callback fired when the value changes. |
| `size` | `'md' | 'sm'` | No | undefined | The size preset to use. |
| `value` | `string` | No | undefined | The controlled value of the selected item. |

## SwitchItem

This component extends all the native `<button>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `value` | `string` | Yes | undefined | The value of the switch item. |
