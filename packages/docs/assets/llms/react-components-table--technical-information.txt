# Table

## Table

This component extends all the native `<table>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `size` | `'lg' | 'md' | 'sm'` | No | undefined | The size preset to use. |
| `variant` | `'default' | 'striped'` | No | undefined | The variant preset to use. |

## Enums

### TABLE_SIZE

- `lg` = `lg`
- `md` = `md`
- `sm` = `sm`

### TABLE_VARIANT

- `default` = `default`
- `striped` = `striped`
