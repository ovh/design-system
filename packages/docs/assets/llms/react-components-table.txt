# Table

_A component to display data in a tabular format._

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `size` | `'lg' | 'md' | 'sm'` | No | undefined | The size preset to use. |
| `striped` | `boolean` | No | undefined | Whether the body rows should alternate background colors. |
