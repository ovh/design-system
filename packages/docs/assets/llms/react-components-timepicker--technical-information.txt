# Timepicker

## Timepicker

This component extends all the native `<div>` attributes.

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultValue` | `string` | No | undefined | The initial time value. Use when you don't need to control the value of the timepicker. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `i18n` | `Partial<Record>` | No | undefined | Internal translations override. |
| `invalid` | `boolean` | No | undefined | Whether the component is in error state. |
| `locale` | `'fr' | 'de' | 'en' | 'es' | 'it' | 'nl' | 'pl' | 'pt'` | No | undefined | The locale used for the translation of the internal elements. |
| `name` | `string` | No | undefined | The name of the form element. Useful for form submission. |
| `onTimezoneChange` | `(detail: TimepickerTimezoneChangeDetail) => void` | No | undefined | Callback fired when the timezone changes. |
| `onValueChange` | `(detail: TimepickerValueChangeDetail) => void` | No | undefined | Callback fired when the value changes. |
| `readOnly` | `boolean` | No | undefined | Whether the component is readonly. |
| `required` | `boolean` | No | undefined | Whether the component is required. |
| `timezone` | `'UTC-12' | 'UTC-11' | 'UTC-10' | 'UTC-9' | 'UTC-8' | 'UTC-7' | 'UTC-6' | 'UTC-5' | 'UTC-4' | 'UTC-3' | 'UTC-2' | 'UTC-1' | 'UTC+0' | 'UTC+1' | 'UTC+2' | 'UTC+3' | 'UTC+4' | 'UTC+5' | 'UTC+6' | 'UTC+7' | 'UTC+8' | 'UTC+9' | 'UTC+10' | 'UTC+11' | 'UTC+12'` | No | undefined | The controlled selected timezone. |
| `timezones` | `'UTC-12' | 'UTC-11' | 'UTC-10' | 'UTC-9' | 'UTC-8' | 'UTC-7' | 'UTC-6' | 'UTC-5' | 'UTC-4' | 'UTC-3' | 'UTC-2' | 'UTC-1' | 'UTC+0' | 'UTC+1' | 'UTC+2' | 'UTC+3' | 'UTC+4' | 'UTC+5' | 'UTC+6' | 'UTC+7' | 'UTC+8' | 'UTC+9' | 'UTC+10' | 'UTC+11' | 'UTC+12'[] | 'all'` | No | undefined | A specific or preset list of timezone to display in the selector. |
| `value` | `string` | No | undefined | The controlled timepicker value. |
| `withSeconds` | `boolean` | No | undefined | Whether the time input allows seconds selection. |
