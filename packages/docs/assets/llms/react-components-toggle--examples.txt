# Toggle

## Default

```tsx
<Toggle>
  <ToggleControl />
</Toggle>
```

## Disabled

```tsx
<Toggle disabled>
  <ToggleControl />
</Toggle>
```

## In form field

```tsx
<>
  <Text preset={ TEXT_PRESET.label }>
    Notification settings:
  </Text>

  <FormField>
    <Toggle>
      <ToggleControl />

      <ToggleLabel>
        General Information
      </ToggleLabel>
    </Toggle>
  </FormField>

  <FormField>
    <Toggle>
      <ToggleControl />

      <ToggleLabel>
        Promotions
      </ToggleLabel>
    </Toggle>
  </FormField>
</>
```

## Invalid

```tsx
<Toggle invalid>
  <ToggleControl />
</Toggle>
```

## With label

```tsx
<Toggle>
  <ToggleControl />

  <ToggleLabel>
    Enable dark mode
  </ToggleLabel>
</Toggle>
```

## With labels

```tsx
<Toggle withLabels>
  <ToggleControl />
</Toggle>
```

## Accessibility - Aria label

```tsx
<Toggle aria-label="Enable dark mode">
  <ToggleControl />

  <ToggleLabel>
    Dark mode
  </ToggleLabel>
</Toggle>
```
