# Tree View

## Props

| Property | Type | Required | Default | Description |
|---|---|---|---|---|
| `defaultExpandedValue` | `string[]` | No | undefined | The initial expanded value(s). Use when you don't need to control the expanded value(s) of the tree view. |
| `defaultValue` | `string[]` | No | undefined | The initial selected value(s). Use when you don't need to control the selected value(s) of the tree view. |
| `disabled` | `boolean` | No | undefined | Whether the component is disabled. |
| `expandedValue` | `string[]` | No | undefined | The controlled expanded value(s). |
| `items` | `TreeViewItem<CustomData>[]` | Yes | undefined | The list of items |
| `multiple` | `boolean` | No | undefined | Whether the multiple selection is allowed. |
| `onExpandedChange` | `(details: TreeViewExpandedChangeDetail) => void` | No | undefined | Callback fired when the expanded value(s) changes. |
| `onValueChange` | `(details: TreeViewValueChangeDetail) => void` | No | undefined | Callback fired when the value(s) changes. |
| `value` | `string[]` | No | undefined | The controlled selected value(s). |
