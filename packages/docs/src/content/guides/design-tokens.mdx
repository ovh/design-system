Design tokens define reusable design values such as colors, borders, and outlines as variables. Instead of using hardcoded values, they provide a consistent, scalable, and maintainable way to style components across all products.

<Heading label="Usage" level={2} />

Design tokens are available as CSS custom properties (variables) and can be used in your CSS files:

```css
.my-component {
  color: var(--ods-semantic-color-content-brand);
  border-radius: var(--ods-semantic-size-radius-control);
}
```

<Heading label="What is guaranteed" level={2} />

The `--ods-semantic-*` tokens are the public surface of the theme: read them in your CSS, re-declare them in a theme. Their names and their meaning do not change during a major version; their values belong to the theme. The `--ods-palette-*` ramps are public too, as the input of a theme: a brand re-declares the `--ods-palette-brand-*` and `--ods-palette-accent-*` ramps.
