*Release notes of the current major version, v20. Earlier versions are listed under <DocLink to="/guides/whats-new-v19">What's new in previous versions</DocLink>; the <DocLink to="/guides/changelog">Changelog</DocLink> lists every change.*

<Heading label="v20.0.0" level={ 2 } />

v20 has breaking changes in the component API and in the theme. Follow the <DocLink to="/guides/migration-19-to-20">Migration 19.x to 20.x</DocLink> guide before you upgrade: run `npx @ovhcloud/ods-migrate .` first, it applies most of the guide to your code.

<Heading label="Project changes" level={ 3 } />

- **React 19** is supported, and React 18 still is: the peer dependency range is unchanged.
- **Themes** are rebuilt on a semantic layer of tokens, and the default theme gets a new, neutral look. Four themes are shipped, each as one complete stylesheet: the default theme (Aluminium), its dark mode, Blue Jeans (the OVHcloud look) and its dark mode. See <DocLink to="/guides/themes">Themes</DocLink>.
- **Documentation** moves from Storybook to a new documentation website, published as `@ovhcloud/ods-docs` in place of `@ovhcloud/ods-storybook`.
- **APIs deprecated in v19 are removed**, the Switch component among them. The `color` prop is removed too, in favor of `status` where the component has one.

<Heading label="New packages" level={ 3 } />

**@ovhcloud/ods-migrate**

Moves the code of an app from ODS v19 to v20: a command that rewrites what has a v20 equivalent and marks what needs a decision, with ESLint and stylelint rules for what is left. <DocLink to="/guides/migration-19-to-20">See Documentation</DocLink>.

**@ovhcloud/ods-mcp**

An MCP server that gives AI assistants access to the ODS documentation. <DocLink to="/guides/mcp-server">See Documentation</DocLink>.

**@ovhcloud/ods-tailwind**

Tailwind CSS v4 utilities mapped to the ODS tokens. <DocLink to="/guides/tailwind">See Documentation</DocLink>.

<Heading label="Feature updates" level={ 3 } />

**Accordion**
- New attribute `emphasis` has been added.

**Badge**
- New attributes `status` and `emphasis` have been added.

**Button**
- New attributes `status` and `emphasis` have been added, `emphasis` replaces `variant`.

**Card**
- New attribute `status` has been added.

**Drawer**
- New attribute `backdrop` has been added. With it, the page no longer scrolls and a click on the backdrop closes the drawer.

**Input**
- New attributes `startContent` and `endContent` have been added.

**Message**
- New attributes `status` and `emphasis` have been added, `emphasis` replaces `variant`.

**Pagination**
- New attributes `getPageUrl` and `linkAs` have been added, to render the pages as links.

**Spinner**
- New CSS custom property `--ods-spinner-color` has been added.

**Table**
- New attribute `striped` has been added, it replaces `variant`.

**Tabs**
- New attribute `mountStrategy` has been added, to choose when the content of the inactive panels is rendered.

**Tag**
- New attribute `status` has been added.

**Toaster**
- New method `toast.accent()` has been added, it replaces `toast.primary()`.

<Heading label="Bug fixes" level={ 3 } />

**Select**
- The hidden native select no longer makes the page taller and scrollable.

**Themes**
- TypeScript 6 accepts the stylesheet imports, such as `import '@ovhcloud/ods-themes/default/css'` and `import '@ovhcloud/ods-react/normalize-css'`.

**Recipes**
- The fields and icon buttons of Chat, Dashboard Card, Data Grid, Data Grid With Query Filter, Range Input and Feature List Product Card have an accessible name.
