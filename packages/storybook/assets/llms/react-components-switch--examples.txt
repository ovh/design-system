# Switch

## Default

---

```jsx
<Switch>
  <SwitchItem value="item-1">
    Item 1  </SwitchItem>
  <SwitchItem value="item-2">
    Item 2  </SwitchItem>
  <SwitchItem value="item-3">
    Item 3  </SwitchItem>
</Switch>
```

## Checked

---

```jsx
<Switch defaultValue="item-1">
  <SwitchItem value="item-1">
    Item 1  </SwitchItem>
  <SwitchItem value="item-2">
    Item 2  </SwitchItem>
  <SwitchItem value="item-3">
    Item 3  </SwitchItem>
</Switch>
```
