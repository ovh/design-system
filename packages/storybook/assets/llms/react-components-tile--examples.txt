## With Checkbox

---

Checkbox tile

```jsx
const [selected, setSelected] = useState(false);
  return <Tile selected={selected}>
      <Checkbox checked={selected} onCheckedChange={detail => setSelected(detail.checked === true)}>
        <div style={{
        display: 'flex',
        alignItems: 'center',
        gap: '8px',
        padding: '16px'
      }}>
          <CheckboxControl />
          <CheckboxLabel>Checkbox tile</CheckboxLabel>
        </div>
      </Checkbox>
    </Tile>;
}
```
